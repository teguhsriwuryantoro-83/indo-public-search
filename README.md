# INDO PUBLIC SEARCH

Web pencarian sumber publik Indonesia dengan fokus pada sumber resmi/terbuka.

## Prinsip
- Tidak menyediakan akses ke database bocor.
- Tidak mencari NIK, KK, kredensial, nomor telepon privat, data kesehatan, atau akses Dukcapil tertutup.
- Hasil nama harus diverifikasi manual; nama yang sama tidak membuktikan identitas yang sama.

## Sumber awal
- Portal Satu Data Indonesia: https://data.go.id/
- Direktori Putusan Mahkamah Agung: https://putusan3.mahkamahagung.go.id/
- Pencarian terbatas domain pemerintah `.go.id`
